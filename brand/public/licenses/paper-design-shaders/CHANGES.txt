Package: @paper-design/shaders 0.0.78 (Apache-2.0, Copyright 2026 Paper)

The package source in node_modules is used unmodified. One modification is
applied at runtime, in brand/src/components/HeroWordmark.jsx, to the exported
string `liquidMetalFragmentShader` before it is compiled:

  1. `vec3 color1 = vec3(.98, 0.98, 1.);`
     replaced with the VORTEX steel highlight stop (#FDFDFD).

  2. `vec3 color2 = vec3(.1, .1, .1 + .1 * smoothstep(.7, 1.3, diagTLtoBR));`
     replaced with the VORTEX steel shadow stop (#6E7B92), keeping the same
     diagonal falloff as a multiplier.

Reason: both stops are shader constants rather than uniforms, and the original
dark stop (0.1) is nearly the same value as the VORTEX stage background
(#101010), which made the dark bands inside the wordmark sink into the page.

No other file from the package is altered.
