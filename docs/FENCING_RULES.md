# 펜싱 실룰 조사 (FENCING_RULES)

> 저장 위치: docs/FENCING_RULES.md
> 용도: arena 룰 심화(R 시리즈)의 사실 근거. 발표에서 "실제 FIE 룰 기반" 주장의 출처.

## [채택 판정 확정] 조사 결과를 간합에 어떻게 반영하는가 (이 표가 본문보다 우선)

| 조사 사실 | 간합 반영 | 이유 |
|---|---|---|
| 부위별 점수 차등은 실제 펜싱에 없음(1투셰=1점) | **점수 균일 유지, 부위는 FUI 라벨로 표시만** | 실룰 정합. 차등을 넣으면 게임적 각색이 됨 |
| 심판기 램프: 선수별 색, 유효=색+부저 | **나=red 램프 / AI=blue 램프 문법 이식.** 초록 미도입 | 좌우 식별이 본질. 초록은 디자인 시스템 파괴 |
| 유효 타겟 부위(무기별 상이) | **판정 미반영(표시만).** 사유를 발표에 정직 명시 | 착탄은 시각 계층(E4). 판정 유입 시 결정성 붕괴 |
| 피스트 14m, 후방 경계 두 발 이탈 = 실점, 경고선 | **게임플레이 채택(R3).** 절대 위치 도입, 라인 몰기 전술 | 결정적 구현 가능, 컨셉 "풋워크 중심"의 완성 |
| 락아웃: 사브르 170ms(봐요), 에페 40~50ms(더블 투셰), 매치포인트 더블 무효 | **게임플레이 채택(R3).** 유파별 동시타 해소 규칙 | 결정적 구현 가능, 유파 차이가 룰 수준으로 |
| 우선권(사브르): 공격>카운터, 리포스트>리메즈, 패리로 이전 | 기존 4분기 판정이 이미 단순화 구현. **동시타 봐요만 추가** | 완전한 우선권 심판은 주관 판정이라 결정적 근사 유지 |
| 기술 카탈로그(플레슈, 발레스트라, 베기 등) | **시각 계층 채택(R4).** 사브르=플런지+베기, 에페=플레슈 | 포즈와 연출, 판정 무관 |
| 사브르 전진 발 교차 금지 → 플런지 | 사브르 유파 시각 정체성으로 채택 | 유파 차이의 시각 근거 |

## 핵심 사실 요약

### 1. 무기별 유효 타겟
- 플뢰레: 몸통만(어깨~허리, 등 포함). 팁만 유효. 오프타겟=흰 램프, 무득점, 액션 정지.
- 에페: 전신(머리~발끝, 손 포함). 팁만. 오프타겟 개념 없음. 팁 압력 750g 초과 시 작동.
- 사브르: 허리 위 전부(몸통, 양팔, 머리. 손 제외). **베기(칼날)와 팁 모두 유효** — 유일한 절단계.

### 2. 점수 — 부위 차등 없음
- 세 무기 모두 유효 부위 명중 = 1투셰 = 1점. 부위 가중치 없음.
- 에페 더블 투셰: 양쪽이 약 40ms(1/25초) 안에 서로 맞히면 둘 다 1점. 단 **동점 매치포인트의 더블은 무효(null and void)**.
- 우선권(플뢰레·사브르만): 공격 먼저 개시한 쪽 우선. 패리 성공 시 방어자에게 이전(리포스트 우선권). 동시 개시 = "시뮬타네(봐요)" 무득점. 위계: 공격>카운터어택, 리포스트>리메즈, 비트 공격>일반 공격. 에페는 우선권 없음.
- 경기 형식: 풀 5투셰 3분(간합의 5점 선취와 일치), DE 15투셰 3x3분.

### 3. 심판기 표시 관례
- 램프: 심판 기준 왼쪽 선수=빨강, 오른쪽=초록(1936년 이래 불변). 오프타겟=흰색(플뢰레·사브르). 부저 동반.
- 락아웃(동시타 판정 창): **사브르 170ms**(2016.8.1부터, 리포스트 장려 목적), **플뢰레 약 300ms**(2004~05 개혁으로 750→350ms, 이후 300ms 인용 병존), **에페 40~50ms 밴드**(40ms 미만 무조건 더블, 50ms 초과 무조건 단일).
- 방송: 초고속 카메라 슬로모 리플레이(액션 3초 전~명중), 최근 AI 궤적 오버레이(Fencing Visualized 계보).

### 4. 기술 카탈로그 (포즈 설계용)
- 앙가르드: 몸 옆으로, 무릎 굽힘, 무기 팔 전방, 뒷팔 균형.
- 런지: 팔 먼저 뻗고 뒷다리 폭발적으로 펴며 앞발 착지. 완성: 앞무릎 90도, 뒷다리 곧게, 뒷팔 뒤로 던짐.
- 어드밴스 런지: 전진 스텝 직후 런지(장거리 한 템포).
- 발레스트라: 앞발 들며 짧게 점프, 양발 동시 착지 후 즉시 런지(거리 교란 홉).
- 플레슈: 팔 뻗고 상체를 앞으로 던지며 뒷다리가 앞다리를 교차해 달려듦. 플뢰레·에페 전용.
- **사브르 발 교차 금지**: 전진 시 뒷발이 앞발을 교차하면 반칙(옐로/레드, 득점 무효) → 플레슈 불가, 교차 없는 "플런지(flunge)"로 대체.
- 사브르 베기: 머리(수직 내려치기), 뺨(대각), 옆구리, 가슴, 팔/손목(스톱컷). 베기 착지가 앞발 착지보다 먼저여야 유효.
- 패리-리포스트: 패리로 우선권 이전, 즉시 리포스트. 늦으면 리메즈에 뺏김.
- 스톱히트: 상대 공격 중 카운터. 에페에서 흔함(먼저 맞히면 득점), 사브르 손목 스톱컷.
- 풋워크: 어드밴스(앞발 먼저), 리트리트(뒷발 먼저), 바운스(제자리 탄성).

### 5. 피스트
- 길이 14m, 폭 1.5~2m. 앙가르드 라인은 중앙 양쪽 2m(시작 간격 4m). 각 선수 후퇴 여유 총 5m. 후방 2m 지점 경고선.
- **후방 경계를 두 발로 넘으면 상대 득점(실점).** 측면 이탈은 정지 + 상대 1m 전진.
- 폭 1.5m가 측면 이동을 봉쇄 → 모든 전술이 전진·후퇴 1차원으로 압축(거리 압박, 라인 몰기, 후퇴 한계 소진).

### 6. 게임 사례
- Fencing VR(Meta Quest): 3종목 AI 대전. Fencer VR: 훈련 드릴 게임화.
- Steam "Fencing": 부위별 데미지 차등(머리>다리>팔>몸통) — **실룰과 다른 게임적 각색의 대표 사례**(우리가 피할 노선).
- Super Fencing System 앱: 실제 심판기 연동, 램프·우선권·타이머 오버레이 리플레이.

### 주의(Caveats)
- 락아웃 정확값은 FIE 재료규칙 부속서 B가 원전. 사브르 170ms(2016.8.1)와 2004~05 개혁은 교차 확인됨. 플뢰레 현행값(300 vs 350ms)은 출처 편차 있어 "약 300ms"로 표기.
- 사브르 발 교차 금지 연도(통상 1988 인용)는 1차 출처 미확정.
- 실제 우선권은 심판 주관 판정. 게임의 룰 기반 자동 판정은 결정적 근사임을 발표에 명시.
