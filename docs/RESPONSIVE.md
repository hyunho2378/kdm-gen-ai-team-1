## 4K·대형 디스플레이 (가장 자주 실패하는 지점)

### 논리 픽셀과 물리 픽셀을 구분하라

32인치 4K(3840×2160)는 OS 배율에 따라 CSS가 인식하는 너비가 달라진다.

| OS 배율 | CSS 뷰포트 너비 |
|---|---|
| 100% | 3840px |
| 150% | 2560px |
| 200% | 1920px |

**동일한 모니터가 세 가지 뷰포트로 나타난다.** 2560에서만 검증하고 끝내면 100% 배율 사용자에게 깨진다. **3840까지 반드시 검증한다.**

### 콘텐츠 최대 너비를 고정 상한 하나로 두지 마라

1440px 상한을 3840px 화면에 적용하면 좌우에 1200px씩 빈 공간이 생겨 사이트가 화면 한가운데 뜬 우표처럼 보인다. 콘텐츠 성격에 따라 전략을 선택한다.

**읽기 중심(문서·기사·본문)**
가독 상한(75ch 내외)은 유지하되 타이포·간격·여백을 clamp로 함께 키워 밀도를 맞춘다. 여백이 남는 것 자체는 정상이나 텍스트만 작게 남지 않게 스케일을 올린다.

**탐색 중심(카드 그리드·갤러리·목록)**
상한을 두지 말고 컬럼 수를 늘린다.
```css
.grid {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(320px, 1fr));
  gap: clamp(1rem, 0.5rem + 1vw, 2.5rem);
}
```

**작업 중심(대시보드·관리 화면)**
전체 너비를 쓰되 사이드바·패널 비율을 유지한다. 데이터 테이블은 화면을 채운다.

### 3840px 최소 요구

1. 좌우 여백이 콘텐츠 너비보다 크지 않을 것
2. 본문 텍스트가 상대적으로 작아 보이지 않을 것
3. 히어로·이미지가 저해상도로 늘어나 흐려지지 않을 것(2x·3x 에셋, SVG, 비디오)

## 유동 스케일링 (브레이크포인트 급변 금지)

레이아웃이 브레이크포인트에서만 계단식으로 바뀌면 그 사이 구간이 어색하고 창을 줄일 때 뚝뚝 끊긴다.

**원칙: 구조 변화에만 브레이크포인트를 쓰고, 크기 변화는 전부 유동값으로 처리한다.**

| 대상 | 방법 |
|---|---|
| 타이포 | `clamp(최소, 기준rem + vw, 최대)` |
| 컨테이너 패딩 | clamp |
| 섹션 수직 간격 | clamp |
| 그리드 | `minmax()` + `fr`, 고정 px 컬럼 금지 |
| 이미지·비디오 | `%` 또는 `aspect-ratio` 기반 |
| 컴포넌트 내부 | 필요 시 컨테이너 쿼리(`@container`)로 부모 폭에 반응 |

브레이크포인트를 써야 하는 경우: 1열→2열 전환, 사이드바 표시·숨김, 모바일 내비→데스크탑 내비 전환 같은 **구조적 재배치**.

## 타이포 스케일 (유동 범위)

| 역할 | 모바일 | 대형 |
|---|---|---|
| H1 | 32 | 64 |
| H2 | 24 | 44 |
| H3 | 20 | 34 |
| H4 | 18 | 26 |
| Body L | 16 | 19 |
| Body | 15 | 17 |
| Small | 13 | 15 |
| Caption | 12 | 13 |

각 값을 clamp로 연결하고 최대값은 3840 기준으로 정한다. **크기별로 tracking과 leading을 함께 조정한다**(큰 제목은 음수 tracking·타이트한 leading, 본문은 tracking 0 근처·여유 있는 leading).

```css
.h1 {
  font-size: clamp(2rem, 1.2rem + 2.4vw, 4rem);
  line-height: 1.05;
  letter-spacing: -0.02em;
}
.body {
  font-size: clamp(0.9375rem, 0.9rem + 0.15vw, 1.0625rem);
  line-height: 1.7;
  letter-spacing: 0;
}
```

## 간격

4pt 배수(4/8/12/16/20/24/32/40/48/64/80/96/128). 섹션 간 수직 여백은 clamp로 화면 크기에 따라 확장한다.

---

## 이미지

- `aspect-ratio` 고정으로 레이아웃 시프트 방지
- `srcset` + `sizes`로 해상도 대응(2x·3x 포함)
- lazy loading
- `max-width: 100%`
- 대형 화면용 고해상도 소스 필수
