# VORTEX 브랜드 사이트 v2 전면 재설계 정리본

기존 brand 표피를 버린다. 레퍼런스 사이트의 정제된 문법을 먼저 세우고, 그 위에 우리 콘텐츠를 끼워 넣는다. 우리 디자인을 강요하지 않는다.

제품은 마스크와 컨트롤러 둘뿐이다. 쇼핑몰이 아니라 브랜드 경험과 비전 중심의 고급 인터랙티브 사이트로 간다.

---

## 0. 실측된 레퍼런스 문법

### Satisfy (히어로 기준) - 실측 완료
- 히어로 제목 24px, weight 900, 자간 -0.48px. 크지 않다. 작고 굵고 자간이 조인다.
- 흰 배경. 강렬한 단일 비주얼 + 짧은 카피 + 살아있는 여백.
- 위계를 크기가 아니라 굵기와 여백으로 만든다.

### Apple Vision Pro (전체 톤 기준) - 실측 완료
- 내비 12px, 본문 14px, 자간 음수. 지원 텍스트가 작고 정밀하다.
- 흰 배경. 시네마틱 스크롤, 제품 딥다이브, 넉넉한 여백.
- 디스플레이 순간(대형 타이포)은 크되, 그 외 모든 텍스트는 작고 절제된다. 제품이 적어도 딥다이브로 풍성하게 느껴진다.

### Rolex (첫 스크롤 이후 3섹션 기준) - 라이브 실측 실패(브라우저 차단)
- 접근이 차단돼 실측을 못 했다. 일반적으로 알려진 문법(전면 이미지 + 짧은 텍스트가 교차하는 정제된 스토리텔링)을 참고 방향으로만 둔다.
- 이 3섹션을 실제 구현하기 전 반드시 재실측한다. 실측 전 추론 구현 금지.

### 공통 결론
절제. 작은 정밀한 타이포, 강한 굵기, 넉넉한 여백, 흰 또는 밝은 배경. 위계는 크기가 아니라 굵기와 자간과 여백이 만든다.

## 1. 새 디자인 시스템

> **BV2-1 완료. 아래 항목은 구현되고 실측으로 확인됐다.** 이 절에 남은 것은 실측으로 바뀐 값들이다.
>
> - **레퍼런스 실측이 0절 요약과 달랐다.** Satisfy의 "히어로 제목 24px/900/-0.48px"는 **워드마크(로고)**이고
>   실제 섹션 헤드라인은 **60 / 48 / 43.2px, 전부 w900**이다. Apple "본문 14px"도 실제로는
>   **본문과 CTA가 17px/400/-0.374px**이고 14px는 국가 배너 링크였다. 내비 12px만 맞았다.
>   **그래서 축소의 대상은 헤드라인이 아니라 136px까지 가던 display였다**(→ 64px).
> - **레드는 `#E60D15`를 못 쓴다.** 그라디언트 최상단 `#C1C1C1` 위에서 **2.63:1**이라 대형 3.0도 미달이고,
>   채움으로 써도 버튼 경계가 2.63이라 UI 요소 3:1에 미달한다. **`#80070C`로 어둡게 내렸다**(5.97 / 9.95).
> - **dim 알파는 0.55가 아니라 0.66이다.** 0.55는 최상단에서 3.5:1로 미달한다.
> - **`scrollbar-gutter: stable both-edges`를 걷었다.** 좌측 15px 띠를 브라우저가 캔버스 배경으로
>   칠하지 않아 배경색과 무관하게 흰 띠가 남는다(fixed 레이어로도 못 덮는다). `stable` 하나로 바꿨다.
> - **스플래시 워드마크 에셋이 흰색이라 라이트에서 안 보였다.** `brand/public/brand/vortex-wordmark.svg`의
>   `fill`을 `#101010`으로 맞췄다(소비처는 brand 프리로더 하나다).
> - **읽기 한도를 변수 하나(`--measure`)로 모았다.** 여섯 파일이 `maxWidth: 720`을 손으로 적고 있었다.
>   리드가 한 줄에 들어가도록 넓혔고, 실측 결과 전 페이지 줄바꿈 0건에 가장 긴 줄이 1000px(한글 약 59자)다.

### 배경
- 페이지 배경 수직 선형 그라디언트. 최상단 #C1C1C1, 최하단 #F6F6F6. 일자 수직.
- 이 그라디언트는 페이지 배경 전용이다. 요소 색이 아니다.

### 색
- 메인 텍스트 #101010.
- 애매한 중간 회색 전량 금지. 텍스트, 보더, 아이콘에 중간 회색 쓰지 않는다. 회색이 필요하면 #101010의 알파나 배경 그라디언트로만.
- 미드나잇 네이비 #263E5F는 브랜드 사이트에서 쓰지 않는다(발표 컬러 시스템 슬라이드 전용).
- 레드는 어두운 곳에서 빛나는 액센트로 최소한만. 라이트 배경이라 레드 사용을 재검토한다(밝은 회색 배경 위 레드 대비 실측 후 결정).

### 타이포 (레퍼런스 기준, 작고 정밀하게)
- 위계를 크기로 벌리지 않는다. Satisfy와 Apple처럼 작고 굵고 자간을 조인다.
- 디스플레이(히어로 딥다이브 순간)만 크게, 나머지 헤드라인은 절제된 중간 크기로 통일.
- 헤드라인 전부 같은 크기 계열. 슬라이드마다 제각각 키우지 않는다.
- 자간 음수(-0.02em 내외), 본문 자간 0 근처.
- 폰트는 Pretendard 유지(브랜드). 확정 폰트 바뀌면 토큰만 교체.
- 불릿 전면 금지. 헤더 현재 선택 상태에도 불릿 금지(굵기와 위치로 표시).

### 마진 그리드
- 전 페이지 단일 그리드. 좌우 거터와 최대폭을 변수 하나로.
- 우측에 자리가 남는데 텍스트가 줄바꿈되는 것 금지. 한 줄에 들어가면 한 줄로. 줄바꿈 한도를 실측하고 넓힌다.

### 모션
- 시네마틱 스크롤(Apple). 절제된 페이드와 이동. 과한 효과 금지.
- 커스텀 커서 유지(R1). 선/라인 장식 금지 유지.

## 2. 사이트 구조 (제품 2개, 경험 비전 중심)

### 페이지
- / 홈. 히어로 + 3 스토리 섹션 + 제품 티저 + 경험 + CTA + 푸터.
- /product/mask, /product/controller. 제품 딥다이브(Vision Pro 방식). 2개뿐이라 각각 깊게.
- /duelists. 유파 3종.
- /experience. 체험 관문.
- /about. 브랜드 소개.

### 홈 섹션 순서와 문법 구분
1. 히어로 (Satisfy 문법). 미니멀. 강렬한 단일 비주얼(이미지 첨부 예정) + 짧은 카피 + 큰 여백. 작고 굵은 타이포. 크롬 워드마크 또는 로고.
2. 스토리 3섹션 (Rolex 문법, 재실측 후 확정). 전면 이미지 + 짧은 텍스트 교차. 세계관, 두 제품의 등장, 결투 개념을 정제된 스토리텔링으로. 각 섹션 이미지 자리 + 짧은 헤드라인.
3. 제품 딥다이브 진입 (Vision Pro 문법). 마스크와 컨트롤러를 시네마틱 스크롤로 소개. 스크롤에 따라 제품이 드러나고 스펙이 딥다이브된다. 2개를 풍성하게.
4. 경험 (Vision Pro). 노트북과 폰으로 겨루는 데모 안내.
5. CTA + 푸터. 절제된 마감.

### 제품명 변경
- XR 글라스를 마스크(Mask)로. 모의 검 컨트롤러를 컨트롤러(Controller)로.
- slug: /product/mask, /product/controller. copy와 라우트 전량 반영.

## 3. UX 라이팅 (결과만, 능동태 명사형 실사용 용어)

검증 기준: 능동태, 주어 동사 서술어 순, 불필요한 조사 제거, 이모지·em대시·가운데점 금지, 명사형 종결, 실사용 UI 용어. 양이 크게 늘거나 줄지 않게. 고칠 게 없으면 유지.

| 자리 | 현재 | 결과 |
|---|---|---|
| 제품 관문 제목 | 검을 이루는 두 개의 장치 | 유지 |
| 제품 관문 한 줄 | XR 글라스와 모의 검 컨트롤러, 훈련을 완성하는 제품군 | 마스크와 컨트롤러, 훈련을 완성하는 두 장치 |
| 유파 관문 제목 | 매번 다른 상대가 마주 선다 | 유지 |
| 유파 관문 한 줄 | 세 유파의 AI 대전자가 거리와 리듬으로 겨룬다 | 유지 |
| 체험 관문 제목 | 지금 거리 안으로 들어선다 | 유지 |
| 체험 관문 한 줄 | 노트북과 폰 하나로 결투를 시작한다 | 유지 |
| 하단 CTA 제목 | 함께 겨루자 | 지금 겨룬다 |
| 유파 셀렉션 안내 | 유파를 선택한다 | 유파 선택 |
| 유파 셀렉션 진입 | 겨루기 | 유지 |
| 뉴스레터 제목 | 결투 소식을 받는다 | 유지 |
| 뉴스레터 안내 | 새 유파와 업데이트 소식을 보낸다 | 유지 |

변경 사유:
- 관문 한 줄: 제품명 변경(마스크 컨트롤러) 반영, 능동 유지.
- 하단 CTA: 함께 겨루자는 청유형이라 명사형 능동으로. 지금 겨룬다.
- 유파 선택: 선택한다는 서술을 실사용 UI 라벨 명사형으로.

나머지는 이미 능동 명사형이라 유지. 억지로 바꾸지 않는다.
