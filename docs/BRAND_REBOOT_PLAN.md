# BRAND REBOOT PLAN — lusion 문법 전면 재현

기존 brand 표피는 잊는다. 라우팅과 기능(Flip, 셀렉션, 뷰어, 햄버거)은 자산으로 유지하되, 레이아웃과 모션과 표면을 전면 교체한다. 목표는 lusion.co의 행동 문법을 우리 브랜드로 재현하는 것.

## 0. 복사의 정의 (규율)

- 복사하는 것: 행동 문법. 프리로더, 커서, 스크롤 워프, 호버 반응, 페이지 전환, 진입 인터랙션, 푸터 리빌. 전부 MCP 실측으로 문서화하고 우리 구현으로 재현.
- 복사하지 않는 것: lusion의 코드, 에셋, 문구, 로고, 고유 비주얼. 코드는 추출 불가능하고 규율(DESIGN 15절) 위반.
- 구현 도구는 확보분만: GSAP(ScrollTrigger, Flip), Lenis, three r0.185, @paper-design/shaders(채택됨), react-creative-cursor(MIT) 또는 자체 커서. 새 도구는 LIBRARIES 게이트 통과 후.
- 정찰 절차: 각 세션 직전 크리틱 창(나)이 lusion 해당 구간을 MCP로 실측해 문법을 이 문서에 추가한다. 클로드코드는 이 문서의 문법 명세만 보고 구현한다. lusion 접속이나 코드 추측 금지.

## 1. 실측된 lusion 문법 (계속 추가)

### 1.1 프리로더 (실측 완료)
- 풀블랙 화면. 중앙에 소형 가로 진행바(흰 채움이 좌에서 우로). 좌하단에 초대형 카운터 숫자(000에서 100, 숫자가 롤링되며 올라감, 화면 밖으로 살짝 잘리게 배치).
- VORTEX 적용: 같은 구조. 카운터 숫자는 Pretendard 세미볼드, 진행바 대신 검끝 한 줄이 좌에서 우로 그어지는 것으로 대체 가능(모티프 통일). 로드 완료 시 프리로더가 위로 걷히거나 페이드되며 스플래시로 이어진다.

#### 구현 확정값 (R2에서 실측으로 굳힌 것)

| 값 | 확정 | 근거 |
|---|---|---|
| 슬라이스 수 | **6** | 2.5절이 허용한 5~7의 가운데. 조각당 시차 0.07초에서 전체 0.85초로 읽힌다 |
| 최소 표시 | **1.2초, 네비게이션 기준** | 효과 실행 시점으로 재면 모듈 파싱만큼 앞당겨져 실측 979ms로 미달했다 |
| 상한 | **5초** | WebGL 차단 실측 3.8초로 그 안에 들어온다 |
| 마지막 구간 이징 | **none** | power2.out은 끝값의 99.5퍼센트에 지속의 93퍼센트에서 닿아 100을 일찍 보여 준다 |
| 슬라이스 등장 | 0.5초, stagger 0.07 | |
| 정지 한 박자 | 0.32초 | |
| 히어로 이동 | 0.7초 power3.inOut | 판이 걷히는 시점도 이 값에 묶인다 |
| 모션 감소 총 시간 | **1초 미만**(실측 0.58초) | 최소 표시 바닥을 0으로 두고 시차와 이동을 뺀다 |

**인계는 히어로 코드를 고치지 않는다.** 오버레이가 `[data-enter="wordmark"]`의 **글리프 상자**를
읽어 그 자리로 날아가 겹친 뒤 판과 함께 사라진다. h1 상자를 그대로 쓰면 line-height 여백 때문에
16px 위에 서서 **워드마크가 둘로 보인다**(실측 스크린샷). 우리 SVG의 viewBox가 글자에 딱 붙은
캡 상자이므로 히어로 쪽도 canvas TextMetrics의 `actualBoundingBox*`로 같은 기준을 구한다.
실측 착지 오차: 스플래시 `[53,378,417]` 대 히어로 글리프 상자 `[53,378,416]`.

**첫 페인트는 index.html의 인라인 배경이 막는다.** 스타일시트가 붙기 전 한 프레임이
흰색으로 번쩍였다(실측). 슬라이스 초기 opacity도 CSS가 쥔다(GSAP set 전 한 프레임 노출 방지).

### 1.2 스크롤 워프 (실측 완료)

**lusion 원본.** body overflow hidden, 문서 높이가 곧 뷰포트, 콘텐츠 래퍼를 transform으로
옮기는 가상 스크롤이다. 스크롤 중 그 래퍼에 off-diagonal 약 0.061(약 3.5도) skew가
willChange transform과 함께 걸리고 정지하면 0으로 돌아온다.

**우리 쪽 사정은 다르다(R3에서 실측).** 우리 Lenis는 네이티브 스크롤을 그대로 민다.
html에 `lenis` 클래스만 붙고 body/html transform은 none이며, 휠에 `window.scrollY`가
실제로 움직인다(0 → 331 → 600). **가상 이동 래퍼가 없다는 뜻이라 skew를 걸 대상을 새로 세운다.**
그래서 스크롤되는 콘텐츠에만 `.vx-warp` 래퍼를 감싸고, 헤더와 커서와 프리로더는 그 밖에 남긴다.

#### 구현 확정값 (R3에서 실측으로 굳힌 것)

| 값 | 확정 | 근거 |
|---|---|---|
| 최대 skew각 | **3도** | lusion 3.5도보다 보수적으로 잡았다 |
| 포화 속도 | **110 px/프레임** | 실측 프레임 델타: 휠 한 번 15, 세게 99, 연타 125, PageDown 311. 평소 빠른 휠이 최대에 닿고 도약만 잘리는 자리다 |
| 속도 곡선 | **제곱** | 저속에서 거의 0이어야 한다. 델타 15면 0.06도(실측 저속 0.000도), 60이면 0.9도 |
| 복귀 | **0.45초 power3.out** | 지속이 끝나는 지점에서 0에 정확히 닿는 이징이라야 아래의 속성 삭제로 넘어간다 |
| 정지 판정 | **0.02도 미만** | 눈에 안 보이는 값 때문에 합성 레이어를 붙들지 않는다 |
| 시계 | **GSAP ticker** | rAF 루프를 하나 더 만들지 않는다. 속도는 `window.scrollY`의 프레임 차분으로 읽는다(Lenis velocity의 정의와 같다) |

**텍스트 선명 복원은 0을 쓰는 게 아니라 속성을 지우는 것이다.** `transform: skewY(0deg)`로
두면 합성 레이어가 남아 글자가 흐린 채로 굳는다. 정지하면 `transform`과 `will-change`를
인라인에서 **삭제**한다. 실측 검증: 워프를 한 번도 안 겪은 렌더와 워프 뒤 정지한 렌더를
같은 자리에서 캡처해 **바이트가 동일**했다(흐림 잔여 0).

**position fixed는 이 래퍼 안에 두지 않는다.** transform이 걸린 조상 안에서 fixed는
뷰포트가 아니라 그 조상을 기준으로 잡힌다. 실측으로 pin 중이던 월드빌딩 섹션이 `main`에
skewY(3deg)를 거는 순간 뷰포트 top 0에서 **-1836으로 날아갔다.** 그래서
헤더·커서·프리로더는 래퍼의 형제로 남기고, 래퍼 안에 남는 유일한 fixed인 ScrollTrigger의
pin은 **`pinType: 'transform'`**으로 바꾼다(실측: pin 구간 전체에서 top 0 유지).

**워프에서 빼야 하는 요소는 같은 각을 빼서 되돌린다.** 히어로 리본 캔버스는 fixed가 아니라
히어로 섹션 안의 absolute라 래퍼 밖으로 낼 수가 없다. skewY는 각이 더해지므로 자식에
`skewY(-θ)`를 걸면 두 행렬의 곱이 정확히 항등이다(실측 합성행렬 `[1,0,0,1]`).
표시는 `data-warp="none"`.

### 1.3 이후 실측 예정 (각 세션 직전)

## 2. 전역 결정 (전 세션 공통)

### 2.1 금지
- 애매한 레드 그라데이션 배경 절대 금지. 레드는 어두운 곳에서 빛나는 레드만(글로우, 발광 요소, CTA). 배경을 붉게 물들이는 radial/linear 그라데이션 전량 제거.
- 장식 선/라인/구분선 전량 제거. 컨셉 구분선, 헤더 헤어라인, 카드 보더 라인 등 선으로 하는 장식 금지. 구분은 여백과 타이포 스케일로.
- 이미지/영상 없는 자리는 "이미지 첨부 예정" 텍스트만(dim). 빈 박스나 다크 사각형 금지.

### 2.2 아이브로우 v2 (DESIGN 4절 개정)
- 불릿 원(레드 점) 제거. 텍스트만.
- 폰트 크기 현재 실측값 +8px. **weight 700 볼드**(원래 600 유지였으나 대비 때문에 개정했다.
  red.light 21px 600은 4.02:1로 본문 기준 4.5에 0.48 모자란다. 700이면 21px가 WCAG 대형
  기준에 들어 3.0으로 통과한다. R4 실측에서 잡았고 값은 `shared/tokens.js` 한 곳이 쥔다).
- 영문 위 국문 아래 스택 유지. 색은 기존(레드 또는 화이트) 유지.
- brand와 presentation-v2 둘 다 적용. presentation-v2는 별도 트랙(P1)으로, brand 세션이 그 폴더를 건드리지 않는다.

### 2.3 마진 시스템
- 페이지 좌우 거터를 전 페이지 단일 변수로 통일(clamp 기반). 페이지마다 다른 마진 금지.
- 제품 인덱스 등 목록 페이지는 첫 화면(100vh, 헤더 제외)에 핵심이 전부 보이게. 스크롤해야 카드가 보이는 배치 금지.
- 세로 리듬은 8pt 배수, 섹션 간격 변수 하나로.

### 2.4 커스텀 커서
- 날카로운 화이트 커서. 기본은 작은 포인트 또는 얇은 크로스헤어, 인터랙티브 요소 호버 시 확대/변형, 클릭 시 수축.
- react-creative-cursor(MIT) 실설치 후 판정, 부적합하면 자체 구현(DOM 2겹 + GSAP). 터치 기기에서는 비활성.

### 2.5 VORTEX 워드마크 SVG
- 파일: brand/public/brand/vortex-wordmark.svg (업로드 원본 반입, viewBox 0 0 570 108, 흰 채움 통짜 path 1개).
- 통짜라 글자별 분리 불가. 스플래시 분할은 세로 클립 슬라이스(5~7조각)로 각 조각이 시차를 두고 드러나는 방식. 글자별 개별 모션이 필요해지면 시각디자이너에게 글자별 path 재내보내기 요청(나중에 교체 전제).

## 3. 구조 개정

### 3.1 제품 재편 (R4에서 반영 완료)
- 인터랙티브 데모 앱은 제품이 아니다. 제품군에서 제거. products는 XR 글라스, 모의 검 컨트롤러 2종.
- 데모 앱 내용은 /experience로 흡수(체험 관문이 곧 데모 앱 소개). copy와 라우트 정리, /product/demo-app은 NotFound.

**흡수는 한 문장이었다.** 데모 앱 문구와 기존 EXPERIENCE를 대조하니 셋이 이미 겹쳤고
(방 코드 연결은 `body` 뒷문장에, 접속·캘리브레이션·결투 3단계는 `steps`에, 노트북과 폰도 `body`에)
없던 것은 **"설치 없이 브라우저에서"** 하나뿐이었다. 그 한 가지만 `EXPERIENCE.body` 앞에 붙였다.
새 자리는 짓지 않았다.

**라우트는 손대지 않아도 사라진다.** App이 `PRODUCTS.cards.map`으로 상세 라우트를 만들므로
카드에서 빼면 `/product/demo-app`이 전역 `*`로 떨어진다(실측: 404 화면).

**제목 두 곳을 "두 개의 장치"로.** 관문 한 줄이 데모 앱을 부르고 있어 남은 둘의 이름으로
다시 썼다. `PRODUCTS.index.line`은 이미 `PRODUCTS_INDEX_LINE_TODO` 자리표시라 그대로 둔다.

### 3.2 About 페이지 신설
- /about. 브랜드 소개. lusion의 어바웃은 참고하지 않는다(과한 구현). 정갈하게: 네이밍 의미(VORTEX), 브랜드 원칙, 팀. 발표의 네이밍/컬러 서사를 사이트 문법으로.
- 헤더 메뉴에 ABOUT 추가(PRODUCTS, DUELISTS, EXPERIENCE, ABOUT).

### 3.3 제품 상세 리레이아웃 (Kew 오크 문법, R4에서 반영 완료)
- 참조 구도: 배경 박스 없이 3D가 페이지 배경 위에 직접 뜬다. 좌측에 페이지 위계(제품명, 탭), 우측에 정보 텍스트가 배경/섹션 박스 없이 얹힌다.
- 현재 4구역 박스형 뷰어를 해체: 뷰어 캔버스를 투명 배경으로 페이지 전체에 깔고, 좌측 상단 제품명과 탭(OVERVIEW/FEATURES), 우측에 스펙/특징 텍스트를 무배경으로. 하단 CTA 유지.
- 3D는 현 플레이스홀더 프리미티브 유지, 실제 GLB는 모델 확정 후.

#### 구현 확정값 (R4에서 실측으로 굳힌 것)

| 값 | 확정 | 근거 |
|---|---|---|
| 겹침 방지 | **격자 열 분리** | 3D는 왼쪽 열, 정보는 오른쪽 열. **오프셋이 아니라 배치로 보증한다.** 열은 서로 겹칠 수 없어 autoRotate가 어느 각도에 있든 성립한다(실측 교집합 0) |
| 열 비율 | 58 대 42, 900px에서 갈린다 | 3D 쪽을 넓게. 그 아래는 한 열로 쌓이고 **3D가 먼저, 정보가 그 아래**라 글자가 3D 위에 얹히지 않는다 |
| 위계 블록 위치 | **격자 밖 위쪽** | 왼쪽 열 안에 두면 세로를 먹어 3D에 240px만 남는다(실측). 밖으로 빼면 남는 세로가 통째로 3D 몫이 된다 |
| 무대 최소 높이 | `min(42vh, 400px)` | 오른쪽 글자 길이가 행 높이를 정하게 두면 3D가 눌린다. 42vh는 900 높이 화면에서 3D가 안 잘리는 상한(실측 바닥 893) |
| 정보 열 | **`grid-column: 2` 못박음** | Flip이 무대를 absolute로 띄우면 격자에 남는 항목이 이것뿐이라 첫 열로 올라와 전환 내내 왼쪽으로 튄다(실측 스크린샷) |

**Flip 짝은 무대가 그대로 받는다. 크로스페이드 폴백은 필요 없었다.** `data-flip-id`를
`.vx-kew-stage`로 옮기니 카드 썸네일이 무대 자리로 확대된다(실측 정방향 22~25개 중간 사각형,
역방향 20개). 무대 안의 자리표시 문구가 날아가는 동안 보이므로 전환이 눈에 읽힌다.

**보존 확인(B8b 회귀 방지).** 컨텍스트 상세당 1, 왕복 3회 누적 0(생성 3 손실 3, 복귀 시 canvas 0),
`touch-action: pan-y` 유지, autoRotate 기본 회전 / 모션 감소 정지, `MODEL_URL`과
`createPlaceholder` 그대로, CTA 채움은 `.vx-cta` 클래스가 계속 쥔다.

## 4. 페이지 흐름 (lusion 리듬)

1. 프리로더(1.1) → 스플래시: VORTEX 슬라이스 등장 → 히어로.
2. 히어로: 크롬 워드마크(셰이더, 유지) + 리본 궤적(유지) + idle에서도 살아 있는 자동 나선. 배경 레드 그라데이션 제거, 순흑 위 빛나는 요소만.
3. 랜딩 섹션 전환: 스크롤 워프. 섹션이 스크롤 속도에 반응해 부드럽게 왜곡/슬라이드되며 넘어간다(Lenis velocity + GSAP skew/scale 근사, 실측 후 명세 확정).
4. 관문/카드: 호버 시 텍스트와 이미지 자리가 반응(이동, 확대, 커서 연동). 진입 시 전환 인터랙션(기존 Flip 자산 활용 + 워프).
5. 하단: CTA 섹션("함께 겨루자" 상당의 우리 카피) → 더 스크롤하면 뉴스레터 구독 블록이 새로 리빌 → 푸터(연락, 링크, 크레딧).
