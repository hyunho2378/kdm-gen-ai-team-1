# PITFALLS.md — 실전 함정과 방지책

프로덕션에서 실제로 반복 발생한 문제들이다. 구현 시 미리 방지하라.

---

## z-index 위계

모달·오버레이·드롭다운·헤더·토스트의 층위를 tokens에 수치로 정의한다. 모달이 헤더 뒤로 가는 사고는 위계표가 없어서 생긴다.

권장 스케일: 콘텐츠 0 / sticky 요소 10 / 드롭다운 30 / 헤더 50 / 오버레이·딤 90 / 모달 100 / 토스트 110.

모달은 딤 스크림(fixed inset-0)과 패널을 함께 최상위로 올리고, body 스크롤을 잠근다.

---

## 서드파티 라이브러리 실패 모드

요소를 숨겼다가 되돌리는 방식(opacity·pointer-events 조작)의 라이브러리는 **실패 시 요소가 영구히 사라지거나 클릭 불가가 된다.**

- 핵심 UI(헤더·내비게이션)에는 이런 라이브러리를 쓰지 않거나, **실패해도 항상 보이는 상태가 기본값**이 되도록 방어한다.
- `pointer-events`는 상속되므로 부모에 걸면 자식 인터랙티브 요소 전체가 막힌다.
- "숨김 → 성공 시 복원" 순서인 라이브러리는 성공·실패 양쪽 경로 모두에서 복원을 호출한다.
- 초기화가 상태 변화마다 재실행되지 않게 의존성 배열을 점검한다(호버할 때마다 재초기화되면 매번 숨김부터 다시 시작한다).

## 브라우저별 검증

Chrome만 보고 끝내지 마라.

- **iOS Safari** — HTML5 드래그앤드롭을 지원하지 않으면서 `draggable="true"` 요소가 자식의 탭(click)을 삼킨다. 터치 기기에서는 `matchMedia('(pointer: coarse)')`로 감지해 `draggable`과 drag 핸들러를 아예 걸지 않는다.
- **Chromium 파생 브라우저(Whale 등)** — 캔버스·WebGL 타이밍이 Chrome과 다르다. WebGL 기반 효과는 실패 폴백이 반드시 있어야 한다.
- **동적 뷰포트** — iOS Safari의 주소창 때문에 `100vh`가 흔들린다. 모달·전체화면 요소는 `100dvh` 또는 JS 기반 높이 계산을 쓴다.

## 다국어 레이아웃 안정성

- 언어 전환 시 컴포넌트를 **리마운트하지 마라.** 등장 애니메이션이 재실행되어 화면이 깜빡인다.
- 텍스트만 교체하고, 길이 차이로 인한 레이아웃 시프트는 긴 언어 기준 `min-height` 예약으로 막는다.
- 전환 시 스크롤 위치를 유지한다.
- 헤더·메뉴 라벨은 활성 언어 하나만 렌더한다(국문·영문 동시 표기 금지).

## 목록·정렬

- 정렬 기준 필드가 비어 있을 때 id 순으로 뒤집히는 사고를 막기 위해 **명시적 타이브레이커**를 둔다.
- 페이지 크기 상한이 전체 목록을 잘라먹지 않는지 확인한다.
- 새로 등록한 항목이 의도한 위치(보통 최상단)에 오는지 실제로 등록해 검증한다.

## 업로드 경합

파일 업로드가 완료되기 전에 저장이 실행되면 URL이 빈 채로 기록된다.

- 업로드 성공 응답을 받은 뒤 저장하도록 순서를 보장한다.
- 실패 시 조용히 넘어가지 말고 사용자에게 알린다.
- 업로드 중 로딩 표시, 완료·실패 피드백을 제공한다.
- 저장 후 목록·상세가 최신 URL을 다시 읽는지 확인한다.

---

## 폼 입력

- 이메일은 형식 검증 후에만 제출 허용.
- 전화번호는 자동 하이픈 포맷팅으로 형식을 강제한다(그 외 문자는 입력 자체를 막는다).
- 비밀번호 확인 필드는 세로로 배치한다(가로 2열은 좁은 화면에서 깨진다).
- 짧은 라벨(3~4글자) 필드에 전체 너비를 주지 말고 2열 배치를 활용한다.
- 필수 항목이 비면 제출 버튼을 비활성화하고, 어느 항목이 비었는지 인라인으로 알린다.

## 네이티브 UI 노출

`<select>`, `<input type="date">`, `<input type="datetime-local">`, 기본 라디오·체크박스는 OS 기본 UI가 그대로 노출되어 디자인 시스템을 깨뜨린다. 커스텀 컴포넌트(드롭다운, 캘린더, 라디오 카드)로 대체하고, 코드베이스 전수 검색으로 잔존 0건을 확인한다.

## 배포·인프라

- **SPA 라우팅** — `client/vercel.json` rewrites가 없으면 새로고침·직접 진입 시 404가 난다.
- **cross-origin 쿠키** — 프론트와 백엔드 도메인이 다르면 `sameSite:'none'` + `secure` + `trust proxy` + `NODE_ENV=production`이 전부 필요하다.
- **CORS** — origin은 끝 슬래시 없이 정확히 일치해야 한다.
- **콜드 스타트** — 무료 티어 백엔드는 일정 시간 후 잠든다. 첫 요청이 실패하는 것처럼 보이므로 uptime 모니터를 두거나 로딩 상태를 명확히 표시한다.
- **환경 종속값** — 도메인·API 주소·토큰을 하드코딩하지 않는다. 계정·도메인 이전 시 값만 바꾸면 되게 한다.
- **OG 이미지** — 절대 URL(https)이어야 한다. 상대경로는 카카오 등 크롤러가 읽지 못한다. SPA는 크롤러가 JS를 실행하지 않으므로 라우트별 동적 메타가 반영되지 않는다(필요하면 프리렌더링 또는 서버리스 주입).

---

## 데이터 무결성

- **비파괴 시드** — TRUNCATE/DELETE 금지. 고유 키 + `ON CONFLICT DO NOTHING`, 기존값은 `COALESCE` 보호.
- **마이그레이션** — DROP 금지, `ALTER TABLE ... ADD COLUMN IF NOT EXISTS`.
- **원문 보존** — 사용자 제공 텍스트는 `SOURCE.md`에 두고 문자 그대로 복사, 시드 후 표본 3건 문자 대조.
- **백업** — 구조 변경·계정 이전 전에는 항상 백업을 먼저 수행한다.

## 진단 원칙

증상이 여러 개 보일 때 "아마 이것 때문일 것"으로 여러 곳을 동시에 고치지 마라.

1. 각 증상을 **실제로 재현**한다.
2. 재현된 것만 **원인을 코드에서 특정**한다.
3. **최소 범위로 수정**한다(수정 파일 수를 보고한다).
4. 각 수정이 어떤 증상을 없앴는지 1:1로 검증한다.
5. 재현하지 못한 증상은 추측으로 고치지 말고, 재현에 필요한 조건을 사용자에게 묻는다.
