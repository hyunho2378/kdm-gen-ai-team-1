# presentation-v2 — 전역 질감 (예약)

설계 지도 v2의 "전역 질감" 항목. **지금 구현하지 않는다. S8까지 다 만든 뒤 마지막 전역 단계에서 얹는다.**
각 섹션은 자기 주인공(선수 프레임, 궤적 리본, 유리 카드 등)을 먼저 완성한다.

## 예약 목록

1. **필름 그레인 + 비네트** — 전 섹션에 얇게. 화면을 한 장의 필름처럼 묶는다.
   구현: postprocessing(Zlib, 설치됨)로 전역 패스. (S2는 임시로 CSS/SVG 그레인을 쓰고 있음 → 이 단계에서 전역 패스로 대체)

2. **마우스 왜곡 바닥(Pixel Distortion)** — S2, S6, S7에 약하게.
   출처: Codrops Pixel Distortion(three.js). 각 섹션 주인공을 해치지 않을 만큼만.

3. **전역 커서 트레일 (신규 예약)** — S1 표지의 Tubes Cursor를 **전 사이트의 통일 모티프로 계승**한다.
   단 풀스크린 빛 튜브가 아니라, **마우스 커서를 따라다니는 얇은 빛 꼬리 하나**로 축소한다.
   모든 섹션에서 마우스를 움직이면 검끝 같은 빛 선이 살짝 따라온다.
   목적: 우리 브랜드 모티프 "검끝이 그리는 곡선 한 줄"을 전 사이트에서 마우스로 느끼게 한다.
   - **은은함**: 각 섹션 주인공(선수 프레임 / 궤적 리본 / 유리 카드 등)을 방해하지 않는 강도. 표지처럼 강하면 안 된다.
   - **성능**: arena 리본 같은 다른 WebGL이 도는 섹션(S3 등)에서도 60fps 사수. 무거우면 트레일을 더 가볍게(세그먼트/블룸 축소, 혹은 2D 캔버스).
   - **범위**: 표지(S1)만 풀 Tubes Cursor 유지. **S2 이후는 이 얇은 트레일 버전으로 통일.**

## 이 단계에서 함께 정리할 성능 항목

- **오프스크린 WebGL 정지**: 현재 S1 Tubes와 S3 리본은 각각 마운트되어 있다. S3는 이미 `active`가 아니면 렌더를 건너뛴다.
  S1 Tubes도 표지 밖에서는 정지시키는 것을 이 단계에서 확정한다(전역 60fps 예산).
